This project is in progress. The page describes the intended scope and acceptance criteria. It does not claim that a dataset has already been cleaned or that any results have been measured.

01 / BUSINESS PROBLEM

Make the dataset safe to analyze

Spreadsheet files can contain missing values, duplicate rows, inconsistent categories, incorrect data types and date or number formats that vary across records. These issues can distort downstream summaries when they are not identified and handled transparently.

The demonstration will use a public, licensed or synthetic dataset that can be shared safely. The source and any restrictions will be documented before analysis.

02 / PLANNED METHOD

A documented sequence of checks

  1. 01
    Profile the raw file

    Record dimensions, column names, data types, missingness, duplicate candidates and basic value distributions.

  2. 02
    Define cleaning rules

    Specify how each issue will be handled before changing data; keep original values where appropriate and avoid silently discarding records.

  3. 03
    Apply repeatable transformations

    Use Excel steps, Python code or both, with clear comments and an auditable log of material changes.

  4. 04
    Validate the output

    Re-run checks, compare row counts and summarize issues resolved, retained and requiring further review.

03 / DELIVERABLES

What the finished project will include

01

Cleaned dataset
A shareable output with no private or restricted records.

02

Quality report
Before/after counts and a concise explanation of cleaning decisions.

03

Reproducible workflow
Code or documented steps another person can review.

04

Analysis-ready handover
Known limitations, unresolved issues and suggested next steps.

04 / SUCCESS CRITERIA

Evidence to publish after completion

The project will be ready to present when the source data and license are documented, the cleaning process can be rerun, validation checks pass, and the final write-up includes genuine before/after figures. Any record removal or value imputation will be explained rather than presented as automatic improvement.
